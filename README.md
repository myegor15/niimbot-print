# Niimbot Printer Client

Данное декстопное приложение дает возможность создавать, редактировать и печатать этикетки для принтеров Niimbot B1.

Приложение состоит из двух модулей: редактора и node.js сервера.


## Редактор

Представляет собой приложение на Java 25 и JavaFX, которое взаимодействует с сервером по REST API. 

Выпоняет следубщие функции:
* создания и редактирования этикеток
* отправки запроса на соединение с принтером
* отобрадежения статуса соединения
* отправки этикеток на печать


## NODE.js сервер

При запуске приложение само поднимает встроенный сервер на случайном свободном порту и подключается к нему.
Для этого не нужно устанавливать node.js — бинарник node и серверные файлы упаковываются в каталог `target/runtime`
при сборке (за это отвечает `frontend-maven-plugin` в `pom.xml`).

Сервер использует библиотеку [niimblue-node](https://github.com/MultiMote/niimblue-node) для соединения с принтером,
которая предоставлет [REST API](https://niimnode-docs.pages.dev/server/) для выолнения следующих функций:
* соединение с принтером
* отсоединения от принтера
* олучения статуса соединения
* получение информации о принтере
* получение информации о RFID
* печать этикеток

Поле «Сервер:» в интерфейсе только для чтения и показывает адрес автоматически запущенного сервера.
Логи сервера выводятся в stdout приложения.


## Запуск

```bash
mvn javafx:run
```

При сборке `frontend-maven-plugin` скачивает node.js (macOS/arm64) в `target/node`, выполняет `npm install` в `server/`
и собирает самодостаточный каталог `target/runtime`. Требуется компилятор (Xcode) для сборки нативных модулей.

Для дистрибутива: `mvn javafx:jlink`, затем скопировать каталог `target/runtime` в образ приложения
рядом с каталогом `app` (jlink не умеет вкладывать дополнительные каталоги сам).

Ручной запуск сервера (без приложения):

```bash
cd server && npm install && npm start
```
