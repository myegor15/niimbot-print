# Niimbot Printer Client

Данное декстопное приложение дает возможность создавать, редактировать и печатать этикетки для принтеров Niimbot B1.

Приложение состоит из двух модулей: редактора и node.js сервера.


## Редактор

Представляет собой приложение на Java 25 и JavaFX, которое взаимодействует с сервером по REST API. 

Выпоняет следубшие функции:
* создания и редактирования этикеток
* отправки запроса на соединение с принтером
* отобрадежения статуса соединения
* отправки этикеток на печать


## NODE.js сервер

Сервер представляет собой приложение на node.js.

Использует библиотеку [niimblue-node](https://github.com/MultiMote/niimblue-node) для соединения с принтером,
которая предоставлет [REST API](https://niimnode-docs.pages.dev/server/) для выолнения следующих функций:
* соединение с принтером
* отсоединения от принтера
* олучения статуса соединения
* получение информации о принтере
* получение информации о RFID
* печать этикеток
